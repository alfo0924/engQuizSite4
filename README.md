<a href="https://alfo0924.github.io/engQuizSite4/">engQuizSite 4 </a>

本英文測驗網站融合了現代前端設計趨勢與學習科技優勢，並以高效、易用、具互動性的方式，協助使用者自我評量英文文法與詞彙能力。以下分為**網站特色優點**與**程式邏輯原理方法**兩大面向說明：

---

## 網站特色與內容優點

- **扁平化設計**  
  採用扁平化設計（Flat Design），色彩鮮明、排版簡潔、元素2D化、無多餘陰影與裝飾，提升可讀性與視覺焦點，避免視覺疲勞，讓使用者能專注於內容[2]。

- **動態漸層霓虹背景**  
  背景以CSS動畫實現紅到藍的緩慢動態漸層（15秒循環），不僅增強視覺吸引力，也有助於聚焦前景內容，提升整體設計層次感[3]。

- **RWD響應式設計**  
  全站採用Bootstrap 5，確保在手機、平板、桌機等不同裝置上皆有一致且友善的瀏覽與操作體驗。

- **符合UI/UX十大原則**
    1. 明確回饋（選項、分數、詳解即時顯示）
    2. 易於操作（大按鈕、清楚標示、選項點擊區明顯）
    3. 資訊架構清晰（分數、錯誤統計、題目解析分區顯示）
    4. 語意化標籤與結構
    5. 鮮明對比與空白設計，減少雜訊
    6. 響應式設計
    7. 一致性（題型、按鈕、配色）
    8. 容錯設計（未作答會提示）
    9. 學習導向（每題詳解、錯誤類型建議）
    10. 互動性佳（送出後自動展開分析）

- **智能分數換算**  
  根據作答自動換算TOEIC（10~990分）與TOEFL（10~120分）預估分數，讓不同需求的學習者都能參考自身程度。

- **詳細錯誤分析與學習建議**  
  每題下方即時顯示正確/錯誤、詳解、錯誤類型與學習建議，並統計全卷常見錯誤類型，協助用戶有針對性地加強弱點。

- **題型涵蓋廣泛且難度分布完整**  
  題庫涵蓋TOEIC/TOEFL常見文法、詞彙、時態、介系詞、比較級、條件句、關係代名詞等，難度從初級到高級，適合0~滿分各級學習者。

## 程式碼運用邏輯原理方法

- **結構分離**  
  採用HTML、CSS、JavaScript三層分離原則，提升維護性與可讀性[4]。

- **題庫資料結構**  
  題庫以JavaScript陣列物件管理，每題包含`type`（toeic/toefl）、`question`、`options`、`answer`、`explanation`、`errorType`欄位。這種結構方便擴充與維護。

- **動態渲染題目與選項**  
  JS於頁面載入時隨機抽取15題，並以迴圈動態產生HTML，確保每題選項格式一致、RWD友善。

- **互動與回饋**  
  送出表單時，JS蒐集所有作答，計算正確數、TOEIC/TOEFL分數，並將每題的正確/錯誤、詳解、錯誤類型與建議直接插入對應題目下方，提升學習效率。

- **錯誤類型統計**  
  JS會統計全卷各錯誤類型題數，並於分數下方顯示，讓用戶一目瞭然自己的弱點。

- **選項視覺狀態管理**  
  送出後，JS依據作答情形為每個選項加上`correct`、`incorrect`、`selected`等class，配合CSS高亮正確答案、標示錯誤選項，提升辨識度。

- **分數換算邏輯**  
  依據答對題數比例，將TOEIC及TOEFL分數以線性方式換算，並顯示於頁面頂端，讓不同考試需求者皆可參考。

- **動態漸層背景**  
  CSS `@keyframes`與`linear-gradient`實現紅到藍的動態漸層，並以`background-size`與`background-position`調整動畫流暢度，提升現代感[3]。

- **RWD與易讀性**  
  Bootstrap網格系統與自訂CSS結合，確保各裝置下字體、間距、按鈕大小皆適宜，並利用空白區域引導視線，符合扁平化設計精髓[2]。
